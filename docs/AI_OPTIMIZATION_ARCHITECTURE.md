# Radiocity AI and Optimization Architecture

## Purpose

Radiocity uses machine learning and optimization as an intelligent layer above the existing physics-based radiative-energy models. The physics model remains the source of truth; data-driven components accelerate prediction and decision-making.

## Current computational direction

```text
Radiation / thermal state
        |
        v
Physics-based models
        |
        +----> LightGBM surrogate / prediction
        |                 |
        |                 v
        +-----------> PSO optimization
                          |
                          v
                   Adaptive controller
                          |
                          v
             Capture / conversion / storage
                          |
                          v
                    Useful output
```

## LightGBM role

LightGBM is the primary machine-learning model for fast prediction and surrogate modelling. Candidate targets include useful electrical power, thermal margin, optimal bandgap, spectral operating parameters, and other quantities generated by the validated physics model or later experiments.

## PSO role

Particle Swarm Optimization is the primary optimization method. It is deliberately implemented as a generic bounded optimizer so it can later optimize bandgap, spectral-filter parameters, thermal operating points, capture allocation, or a near-field separation parameter when an appropriate near-field model exists.

## Reinforcement learning

RL is a future research pathway, not part of the current implementation. It should only be introduced after the physics, LightGBM surrogate, PSO optimization, and adaptive-control framework have been validated.

## Research boundary

No claim is made that the current repository provides real-time physical actuation of spectral filters or near-field vacuum gaps. Those are candidate control variables for future modelling and experimental collaboration.
